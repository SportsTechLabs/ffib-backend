# ⚽ FFIB 2.0 — Backend

Backend oficial de **FFIB 2.0**, desarrollado con Spring Boot y diseñado siguiendo principios de Clean Architecture y Domain-Driven Design.

---

## 🚀 Descripción

Este repositorio implementa toda la lógica de negocio de la plataforma.

Incluye:

- Autenticación
- Gestión de usuarios
- Clubes
- Competiciones
- Noticias
- Administración
- IA
- Seguridad
- API REST

---

## 🛠️ Stack Tecnológico

### Core

- Java 21
- Spring Boot 3

### Persistencia

- PostgreSQL
- Spring Data JPA
- Hibernate
- Flyway

### Seguridad

- Spring Security
- JWT
- OAuth2 (futuro)

### Caché

- Redis

### Calidad

- MapStruct
- Bean Validation
- Lombok

### Testing

- JUnit 5
- Mockito
- Testcontainers
